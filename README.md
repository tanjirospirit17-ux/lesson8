# Инструкция для наставника по запуску тестов

Для успешного выполнения автотестов необходимо настроить переменные окружения, так как данные для авторизации не хранятся в коде в целях безопасности.

## Необходимые данные

1. **`YOUGILE_API_KEY`** — ваш действующий API-ключ от YouGile.
   - *Где взять:* В настройках профиля YouGile под аккаунтом администратора перейдите в раздел "API" или "Ключи API" и создайте новый ключ.
2. **`YOUGILE_BASE_URL`** (опционально) — базовый URL API. 
   - *Значение по умолчанию:* `https://yougile.com/api-v2`

## Настройка окружения

### Способ 1: Через файл `.env` (Рекомендуемый)
Создайте в папке `lesson_08` файл `.env` со следующим содержимым:
```env
YOUGILE_API_KEY=ваш_реальный_api_ключ_здесь
YOUGILE_BASE_URL=https://yougile.com/api-v2
